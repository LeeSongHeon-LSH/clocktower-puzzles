# 퍼즐 제작 가이드

작성: 2026-09-02. 이 문서는 **퍼즐을 만드는 사람(또는 모델)이 처음부터 끝까지 따라가는 절차서**다.
대본(역할 풀) 제약은 솔버 코드의 검증 규칙을 그대로 옮긴 것이므로, 여기 적힌 대로 만들면
`npm test`의 구조 검사는 통과한다. 유일해는 별개다 — 그건 만들어 보고 돌려 봐야 안다.

읽기 전 전제: `docs/REQUIREMENTS.md` §2.1~§2.5, `docs/ARCHITECTURE.md` §3~§4.
역할 모델링의 세부는 `docs/REQUIREMENTS.md` §2.4의 차수별 항목과 `docs/design/pithag.md`,
`docs/design/goon.md`에 있다. 이 문서는 그것을 **제작자 관점으로 다시 정리**한 것이다.

---

## 0. 한 문단 요약

퍼즐은 "모든 좌석이 역할과 밤 정보를 공개 주장한 상황"에서 **지금 이 순간의 악마가 누구인가**를
묻는다. 정답 그리모어를 먼저 정하고, 그 그리모어에서 선한 좌석이 실제로 받았을 정보를 계산해
주장으로 옮기고, 악역의 거짓말을 끼워 넣은 뒤, 솔버(`npm test`)가 **해가 정확히 하나**임을
증명하면 배포할 수 있다. 재미는 유일해 위에 따로 얹어야 한다 — 이 문서의 §9.

---

## 1. 제작 흐름

```
1. 트릭 하나를 고른다 (§9 카탈로그)          → "이 퍼즐의 지렛대는 무엇인가"
2. 인원·밤 수·대본을 정한다 (§3, §4, §5)     → 구성표와 조합 거부표를 먼저 본다
3. 정답 그리모어(solution)를 적는다          → 좌석 → 실제 역할, 악마 좌석
4. 사건 원장(events)을 적는다                → 처형·밤 사망·낮 행동
5. 선한 좌석의 진실 주장을 '계산'한다        → §6의 역할별 규칙대로, 정답 세계에서 실제로 본 값
6. 악역·숨은 외부인의 거짓 주장을 넣는다     → 정직한 주장과 구별 안 되게
7. 솔버를 돌린다 (§2.3)                      → 0개면 모순 찾기, 2개 이상이면 구별 정보 추가
8. 해설·힌트·질문을 쓴다 (§10)               → 해설의 논증은 솔버가 검증하지 않는다 — 사람이 본다
9. 파일을 등록하고 npm test 전체를 돌린다    → 통과해야 배포 가능
```

5번이 핵심이다. **주장은 지어내는 것이 아니라 정답 세계에서 계산하는 것이다.** 선한 좌석이
"실제로 그 밤에 보았을 값"과 다른 주장을 넣으면 솔버는 그 세계를 버리고, 저자는 왜 0개인지
한참 헤맨다.

## 2. 파일 형식과 한계값

### 2.1 파일

`src/data/puzzles/<id>.ts` 하나 = 퍼즐 하나. `definePuzzle({...})`로 내보내고
`src/data/puzzles/index.ts`에 import와 배열 등록을 추가한다. 아이디 관례: `tb-NN`(TB 단일 판본),
`mx-NN`(혼합), 앞으로 `bmr-NN`·`sv-NN`도 가능.

| 필드 | 형식 | 규칙 |
|---|---|---|
| `id` | `"tb-07"` | 파일명과 같게 |
| `title` | 문자열 | 60자 이하 |
| `edition` | `"tb" \| "bmr" \| "sv" \| "mixed"` | `mixed`가 아니면 **대본의 모든 역할이 그 판본**이어야 한다 (테스트가 검사) |
| `difficulty` | `"easy" \| "normal" \| "hard"` | §9.4 기준 |
| `playerCount` | 5~10 | §3 구성표 |
| `nights` | 1~5 | 경과한 밤 수. 현재 시점 = `nights`일차 낮, 처형 전 |
| `rolePool` | 역할 id 배열 | **대본. 풀이 화면에 공개된다.** §4 |
| `intro` | 문자열 (선택) | 상황 도입. 300자 이하 권장 |
| `claims` | 좌석별 주장 | **전 좌석 필수**, 좌석당 정보 5건 이하 |
| `events` | 사건 배열 | §3.2 |
| `questions` | 질문 배열 | 첫 질문은 반드시 `id: "demon"`. 5개 이하. §10.3 |
| `hints` | 문자열 배열 | **최대 2개**. 안 쓰면 `[]` |
| `walkthrough` | 문자열 배열 | **1개 이상 필수**, 공유 링크 한도는 12개 |
| `solution` | 역할 id 배열 | 길이 = `playerCount`, 악마 정확히 1명, 전부 대본 안 |
| `currentDemonSeat` | 좌석 (선택) | 승계(스타 패스·탕녀·팡 구·뱀 조련사)가 있었으면 **반드시** 적는다 |
| `realGame` | boolean (선택) | 실제 판 기록일 때만 |

### 2.2 배포 게이트 (`tests/puzzles.test.ts`)

퍼즐마다 다음이 전부 통과해야 한다.

1. 구조 검사 — §5의 모든 규칙 (`analyze`가 던지지 않아야 한다).
2. 질문 정답이 `solution`에서 도출된다 — `demon`은 현재 악마 좌석, 역할 id는 그 역할의 좌석들.
3. 스키마 — `solution` ⊂ 대본, 힌트 ≤ 2, 판본 태그 일치.
4. **유일해** — 전수 탐색 결과가 정확히 1개이고 `solution`·`currentDemonSeat`와 같다.
5. 예외: 솔버가 능력을 모르는 역할(실험적 역할)이 배정될 수 있으면 4번만 건너뛰고 해설을 요구한다
   (미검증 레인 — 실제 판 기록용. **새로 만드는 퍼즐은 이 레인을 쓰지 않는다**).

### 2.3 초안을 돌려 보는 법

에디터(`/create`)에 넣어도 되지만, 파일로 만드는 중이라면 임시 테스트가 빠르다.
`tests/solver/zz-scratch.test.ts`를 만들고 (커밋 전에 삭제):

```ts
import { it } from "vitest";
import { solve } from "@/lib/solver/solve";
import draft from "@/data/puzzles/tb-07"; // 아직 index에 등록 안 해도 된다

it("draft", () => {
  const worlds = solve(draft);
  console.log("해 개수:", worlds.length);
  for (const w of worlds.slice(0, 10)) {
    console.log(w.assignment.join(","), "악마", w.currentDemonSeat,
      "독살", JSON.stringify(w.poisonTargets), w.goonEvil === undefined ? "" : `건달악:${w.goonEvil}`);
  }
});
```

`npx vitest run tests/solver/zz-scratch.test.ts --reporter=verbose`로 돌린다. 해가 여럿이면
**출력된 세계들을 나란히 놓고 무엇이 다른지** 본다 — 그 차이를 가르는 정보 하나를 추가하는 것이
7번 반복의 전부다. 0개면 §11의 흔한 원인부터 본다.

## 3. 시간축과 사건 원장

### 3.1 시간 규약

```
밤1 → 낮1 → 밤2 → 낮2 → … → 밤k → (현재: k일차 낮, 처형 전)     k = nights
```

- **첫 밤(밤1)에는 아무도 죽지 않는다.** 밤1 사망 이벤트는 거부된다.
- 밤 n의 정보 역할은 **그 밤의 킬 이후** 상태를 본다 (초공감자의 이웃, 장의사 등).
- 낮 정보 역할(화가·학자)은 `night: n`을 **낮 n**으로 해석한다.
- 생존자가 2명 이하가 되는 순간 게임이 끝난다 — 그런 상태까지 진행된 퍼즐은 만들 수 없다.
- 이벤트에 없는 밤은 "아무도 죽지 않은 밤", 없는 낮은 "처형 없는 낮"으로 **그대로 단서가 된다**.

### 3.2 사건 종류와 허용 범위

| 사건 | 필드 | 범위 | 비고 |
|---|---|---|---|
| `execution` | `day, seat` | 낮 1 ~ k−1 | 낮마다 1건. 현재 낮(k)은 처형 전이라 불가 |
| `death` | `night, seat` | 밤 2 ~ k | 한 밤에 여러 건 가능 — 단 §7.2의 귀속 수단이 있어야 한다 |
| `slayerShot` | `day, seat, target, died` | 낮 1 ~ k | 누구든 사냥꾼을 주장하며 쏠 수 있다(허세 포함). 현재 낮도 허용 |
| `nomination` | `day, nominator, nominee` | 낮 1 ~ k | 아무 일도 없었던 지명. 처녀 소진·미발동 강제에 쓰인다 |
| `virginTrigger` | `day, nominator, nominee` | 낮 1 ~ k−1 | 지명자가 즉시 처형됨 = 그날의 처형. 같은 날 `execution` 불가 |
| `vote` | `day, seat` | 낮 1 ~ k | 부분 기록. 죽은 좌석도 가능(유령 투표). 꽃파는 소녀와 짝 |

죽은 좌석이 또 죽거나 처형되거나 낮 행동에 참여하면 거부된다.

## 4. 구성 규칙 — 누가 몇 명인가

### 4.1 기본 구성표

| 인원 | 마을 주민 | 외지인 | 하수인 | 악마 |
|---|---|---|---|---|
| 5 | 3 | 0 | 1 | 1 |
| 6 | 3 | 1 | 1 | 1 |
| 7 | 5 | 0 | 1 | 1 |
| 8 | 5 | 1 | 1 | 1 |
| 9 | 5 | 2 | 1 | 1 |
| 10 | 7 | 0 | 2 | 1 |

### 4.2 외지인 수정치 (텔러 선택은 양쪽 다 탐색된다)

| 역할 | 효과 |
|---|---|
| 남작 (Baron) | 외지인 +2, 주민 −2 |
| 대부 (Godfather) | 외지인 +1 **또는** −1 — 두 경우 모두 열거 |
| 팡 구 (Fang Gu) | 외지인 +1 |
| 비고르모르티스 (Vigormortis) | 외지인 −1 (0 밑으로는 안 내려감) |

**함정**: 7인·5인·10인은 외지인 0명이라 **외지인을 주장하는 좌석이 있으면 그 좌석은 거짓말쟁이**다
(남작 등이 없다면). 반대로 8인·6인은 외지인이 정확히 1명이어야 하므로, 외지인 주장이 없으면
**숨은 외지인이 반드시 있다**(§4.3). 이것만으로도 퍼즐 하나가 된다 (`tb-05`).

### 4.3 숨은 외지인 슬롯

주민을 주장하는 선한 좌석 하나가 실제로는 다음 중 하나일 수 있다 — **풀에 있을 때만**:

| 역할 | 자기 정체 | 주장 | 밤 기상 |
|---|---|---|---|
| 주정뱅이 (Drunk) | 모른다 — 주민이라 믿는다 | 믿는 역할, 정보는 텔러 재량(임의) | 믿는 역할대로 |
| 광인 (Mutant) | 안다 — 외지인임을 숨긴다 | 주민 사칭, 전부 날조 | 깨지 않는다 |
| 미치광이 (Lunatic) | 악마라고 착각 | 전부 날조 | 악마처럼 밤마다 |
| 건달 (Goon) | 안다 | **지금 악할 때만** 사칭 가능 | 깨지 않는다 |

규칙: `외지인 슬롯 − 공개 외지인 주장 수`가 **0 또는 1**이어야 한다. 2 이상이면 해가 0개다
(숨은 외지인은 한 명뿐). 세레노부스의 광기 좌석이 외지인이면 그것도 슬롯을 채운다.

## 5. 대본(rolePool) 제약 — 전부

여기 적힌 규칙은 `validatePuzzle`이 던지는 오류와 1:1이다. 어기면 구조 검사에서 **즉시 거부**된다.

### 5.1 일반 규칙

| 규칙 | 오류 메시지 |
|---|---|
| 풀에 같은 역할이 두 번 | `역할 풀에 중복이 있습니다` |
| 풀에 악마가 하나도 없음 | `역할 풀에 악마가 없습니다` |
| 풀에 있는 역할이 솔버 미지원(실험적 역할)이고 **배정될 수 있는 자리**에 있음 | `솔버가 아직 모르는 역할입니다: …` → 미검증 레인 |
| 주장한 역할이 풀에 없음 | `풀에 없는 역할 주장: …` |
| 주장이 없는 좌석 | `좌석 N의 주장이 없습니다 (전원 공개 주장 형식)` |
| 한 좌석에 주장 두 개 | `좌석 N의 주장이 중복` |
| 정보의 밤이 1~k 밖 | `좌석 N: 정보 밤 범위 밖` |
| 정보 `data.type`이 (당시) 역할과 다름 | `당시 역할(…)과 정보 타입(…) 불일치` |

**배정될 수 있는 자리**란: 풀의 하수인·악마 전부, 주장된 역할 전부, 숨은 외지인(§4.3), 마귀할멈
변신 전 역할, 그리고 **세레노부스가 풀에 있으면 풀의 모든 선한 역할**. 은둔자·첩자의 오등록
대상으로만 쓰이는 역할(아무도 주장하지 않는 주민 등)은 배정되지 않으므로 미지원이어도 통과한다.

**풀은 넉넉하게.** 좌석 수와 같은 개수면 대본이 정답을 알려준다. 수록 퍼즐은 17~36종이다.
유일해가 유지되는 한도까지 넓힌다 — 넓힐수록 풀이자가 세워야 할 가설이 늘어 재미가 는다.

### 5.2 주장 규칙

| 규칙 | 이유 |
|---|---|
| **주정뱅이·광인·미치광이·악마는 주장할 수 없다** | 자기 정체를 모르거나 감춘다. 주정뱅이는 믿는 주민 역할을 주장한다 |
| 하수인·외지인·주민은 주장할 수 있다 | 악역이 하수인을 주장하는 허세, 은둔자·집사·성자·건달의 정직한 외지인 주장 |
| 좌석당 정보 5건 이하 | 공유 링크 한도 |
| 화가의 질문은 게임당 1회 | |
| 철학자의 능력 획득은 게임당 1회, 획득 역할은 `PHILOSOPHER_GAINABLE` 안 | §6.3 |
| `asRole`(당시 역할)은 이발사가 풀에 있거나, 그 주장에 `roleChange`가 있거나, 철학자 획득 정보일 때만 | |
| 정보성 주장은 **최종 진실 주장 하나만** | 낮에 떠보기로 다른 역할을 사칭한 이력은 `text`(서사, `data` 없음)로만 |

### 5.3 조합 거부표 — 같은 대본에 넣을 수 없는 쌍

솔버가 아직 함께 다루지 못하는 조합이다. 풀에 두 역할이 같이 있으면 **배정 여부와 무관하게** 거부된다.

| 이 역할이 풀에 있으면 | 이 역할들은 못 넣는다 | 이유 |
|---|---|---|
| 보르톡스 (Vortox) | 마스터마인드 | 연장 밤의 거짓 강제 해제 미처리 |
| 팡 구 (Fang Gu) | 스위트하트 | 점프한 스위트하트의 능력 상실 미처리 |
| 이발사 (Barber) | 주정뱅이·광인·미치광이·세레노부스·팡 구·**건달** | 주장 날조 수단이 숨은 교환을 은닉한다 |
| 이발사 | (10인 퍼즐 전체) | 하수인 2명 간 교환이 주장에 안 드러난다 |
| 이발사 | (하수인 역할 **주장**) | 악역이 낀 교환 열거 없음 |
| 뱀 조련사 (Snake Charmer) | 이발사·팡 구·좀부울·탕녀 | 교환 토큰과 승계·가짜 죽음의 교차 |
| 마귀할멈 (Pit-Hag) | 주정뱅이·광인·미치광이·**건달**·팡 구·이발사·뱀 조련사·철학자 | 날조가 변신을 은닉 / 타임라인 교차 |
| 건달 (Goon) | 이발사·마귀할멈 | (위 두 줄의 역방향) |

### 5.4 역할별 대본 조건

| 역할 | 대본이 만족해야 하는 것 |
|---|---|
| **마귀할멈** | 풀의 하수인은 **마귀할멈 하나**, 악마는 **한 종류**, **9인 이하**. 따라서 마귀할멈 퍼즐에는 독살범이 없다 — 취함·중독 원천은 §8의 다른 것들뿐 |
| 마귀할멈 변신 이력 (`roleChange`) | 변신 밤 2~k, 변신 전 역할은 대본 안이고 `SWAPPABLE_ROLES` 안, 현재 역할은 `PHILOSOPHER_GAINABLE` 안, 둘이 다름. 변신 전 밤의 정보는 `asRole: from`, 변신 후 정보엔 `asRole` 없음. 좌석당 1회 |
| **세레노부스** | 풀의 선한 역할 전부가 배정 가능해지므로 **미지원 선한 역할이 하나라도 있으면 거부** |
| **이발사** | 9인 이하, 하수인 주장 금지, `asRole` 이력은 `SWAPPABLE_ROLES` 안에서만 |
| **철학자** | 획득 역할은 `PHILOSOPHER_GAINABLE` (= SWAPPABLE에서 점쟁이·저글러 제외), 사용 밤 이후의 획득 정보에 `asRole: 획득역할` |
| **탕녀** | 승계가 있는 정답이면 `currentDemonSeat`를 반드시 적는다 |
| **팡 구** | 점프가 있는 정답이면 `currentDemonSeat` 필수. 외지인 +1 |
| **뱀 조련사** | 교환 세계는 옛 악마 좌석이 **최종적으로 뱀 조련사를 주장**할 때만 성립 (고백 주장) |
| **보르톡스** | 지나간 낮(1~k−1) **전부에 처형**이 있어야 보르톡스 세계가 성립 — 없으면 보르톡스는 자동 탈락 |
| **마스터마인드** | 연장은 정확히 하루라 **마지막 낮(k−1)의 악마 처형**일 때만 현재에 닿는다 |
| **좀부울** | 첫 죽음은 가짜(등록상 사망, 비밀 생존) — 같은 좌석의 두 번째 사망은 표현 불가 |
| **군인·수도사 등** | 이발사·마귀할멈의 교환/변신 대상이 될 수 없다 (`SWAPPABLE_ROLES` 밖) |

`SWAPPABLE_ROLES` = 세탁부·사서·수사관·요리사·초공감자·점쟁이·장의사·까마귀지기·시계공·몽상가·
신탁·저글러·수학자·객실 청소부·꽃파는 소녀·마을 서기·학자·화가·시장.
`PHILOSOPHER_GAINABLE` = 위에서 점쟁이·저글러를 뺀 것.

### 5.5 판본 태그

`edition`이 `tb`/`bmr`/`sv`면 대본의 **모든** 역할이 그 판본이어야 한다. 하나라도 섞이면 `mixed`.
`mixed`는 난이도와 무관하다 — 어려운 TB 퍼즐(`mx-04`는 `tb`)도, 쉬운 혼합 퍼즐도 가능하다.

### 6.4 이번에 편입된 두 역할 — 제작 관점 요약

**마귀할멈**: 퍼즐의 재료는 "나는 원래 X였는데 밤 n부터 Y가 됐다"는 이력 주장 하나다. 그
주장이 진짜인지(정직한 선인의 변신) 허세인지(악역의 거짓말)가 퍼즐이다. 진짜라면 그 밤
마귀할멈이 살아 있고 멀쩡했고 Y가 판에 없었어야 한다. 처형된 마귀할멈 시신이 장의사에게
마을 주민으로 보이는 것(자기 변신)이 두 번째 재료다. 대본은 §5.4대로 좁다 — **독살범이
없으므로** 취함은 대신·선원·여관주인·스위트하트·철학자(단, 철학자는 조합 거부)로만 만든다.

**건달**: 퍼즐의 재료는 **조용한 밤**과 **진영 판정의 흔들림**이다. 아무도 안 죽은 밤을 "악마가
건달을 골라 취했다"로 설명할 수 있고, 그러면 건달은 악해진다. 초공감자·요리사·재봉사·신탁이
세는 악에 지금 악한 건달이 들어간다. 건달을 죽이려면 그보다 먼저 건달을 고른 사람(독살범 등)이
있어야 한다. 지금 악한 건달은 주민을 사칭할 수 있어 숨은 외지인 슬롯도 채운다. **같은
그리모어라도 건달의 진영이 다르면 다른 해**이므로, 유일해를 만들려면 진영까지 못박는 정보가
필요하다 (예: 마지막 밤의 초공감자·신탁).

## 7. 밤 사망의 회계 — 죽음이 없는 밤, 여럿 죽은 밤

솔버는 **밤마다 악마의 킬 시도를 설명**하라고 요구한다. 이것이 제작에서 가장 자주 부딪히는 벽이다.

### 7.1 아무도 안 죽은 밤(밤2 이후)에는 설명이 하나 있어야 한다

다음 중 하나가 그 밤에 성립해야 한다. 없으면 그 세계는 죽는다 — 대본에 아무것도 없으면 **해 0개**.

| 설명 | 조건 |
|---|---|
| 악마가 중독/취함 | 독살범(살아 있고 멀쩡), 대신(악마 역할 지정), 선원·여관주인의 취함이 악마에 |
| 군인을 노렸다 | 군인이 살아 있고 멀쩡 |
| 수도사가 막았다 | 수도사가 살아 있고 멀쩡 (기록이 있으면 그 대상이 살아 있어야) |
| 찻집 여인의 이웃을 노렸다 | 이웃 둘이 선으로 등록될 수 있음 |
| 멀쩡한 선원을 노렸다 | |
| 여관주인이 보호했다 | 밤2+ |
| 어릿광대가 회피했다 | 회피 미사용 |
| 구마사제가 봉쇄했다 | 기록이 악마이거나 기록 없음 |
| **악마가 건달을 골라 취했다** | 건달이 살아 있고, 기록된 정직한 선택자가 그보다 먼저가 아님 |
| 포의 자발적 휴식 | 다음 밤 3명 (다음 밤 사망 0~3건 자유) |
| 샤바로스 | 항상 공짜 |
| 좀부울 | 직전 낮 처형 있을 때 공짜 |
| 푸카 | 선택 무효·선택 실패·처형자 선택·죽음 단계 무산 |
| 마스터마인드 연장 밤 | 악마가 죽은 뒤 |

### 7.2 여럿 죽은 밤에는 귀속 수단이 그만큼 있어야 한다

악마 킬은 보통 1건(포 3킬 밤은 3, 샤바로스 2). 나머지는 다음에 귀속되어야 한다:

암살자(1회, 보호 무시) · 대부(낮 외지인 처형 다음 밤) · 할머니 연쇄(손주가 악마에게 죽을 때) ·
도박사 오답 · 땜장이(자유) · 달의 자손 저주(죽은 다음 밤, 선한 대상) · 소문꾼(∃) ·
임프 자살(스타 패스) · 팡 구 점프(악마 좌석 사망 + 외지인 승계).

한 밤에 3명이 죽었는데 대본에 암살자·대부·할머니·땜장이가 없으면 해 0개다.

### 7.3 죽음이 걸리는 제약 (희생자 쪽)

멀쩡한 군인·선원·찻집 여인 이웃·어릿광대(미회피)·수도사 보호 대상·여관주인 보호 대상은
악마에게 죽지 않는다 → 죽었다면 **그 밤 보호자/본인의 중독이 강제**된다. 독살범이 없는 대본에서
이런 죽음을 넣으면 해 0개다 (암살자는 보호를 관통한다).

## 8. 취함·중독의 원천 — "틀린 정보"를 만드는 방법

정직한 선인이 틀린 정보를 냈다면 그 밤 취했거나 중독됐어야 한다. 솔버는 원천을 역산한다.
대본에 원천이 없으면 틀린 정보는 곧 "그 좌석은 거짓말쟁이(악역)"가 된다.

| 원천 | 대상 | 지속 | 비고 |
|---|---|---|---|
| 독살범 | 밤마다 1명 (살아 있는 좌석) | 그 밤 + 다음 낮 | 취한 독살범의 독은 안 듣는다. **건달은 대상 불가** |
| 주정뱅이 | 자기 자신 | 영구 | 정보는 임의값 |
| 스위트하트 | 죽은 뒤 1명 (∃) | 영구 | 사망 시 중독이면 미발동 |
| 선원 | 나 또는 대상 (매밤) | 그 밤 | 기록 없는 밤은 대상 미상 |
| 여관주인 | 보호한 둘 중 하나 (밤2+) | 그 밤 | |
| 대신 | 지정 역할 토큰 (1회) | 3밤 3낮 | 게임에 없는 역할이면 소진만 |
| 철학자 | 획득 역할의 원주인 | 영구 | 원주인이 있을 때만 |
| 음유시인 | 전원 | 하수인 처형 다음 밤 | 그 밤엔 킬도 독살도 정보도 없다 |
| 노 다시 | 양옆 가장 가까운 주민 | 상시 | 관대 집합 — 확정 아님 |
| 비고르모르티스 | 죽인 하수인의 이웃 주민 1명 | 그때부터 | 관대 집합 |
| 푸카 | 선택한 좌석 | 선택 밤 + 다음 밤 | 그 좌석은 다음 밤 죽는다 |
| **건달** | 자기를 고른 첫 사람 | 그 밤 + 다음 낮 | 고른 사람의 진영이 된다 |
| 세레노부스 | (취함 아님) 광기 — 주장 전체 날조 | 마지막 밤 선택 | |

**제작 팁**: 원천을 **하나만** 두면 틀린 정보의 범인이 그것으로 수렴한다 — 쉬운 퍼즐. 원천이
둘이면(독살범 + 주정뱅이) "이 정보는 독인가 술인가"가 퍼즐이 된다 — 보통. 원천이 셋 이상이거나
관대 집합(노 다시·푸카)이 끼면 유일해 만들기가 급격히 어려워진다.

## 9. 재미있는 퍼즐 — 유일해 위에 얹는 것

### 9.1 원칙

1. **지렛대 하나.** 좋은 퍼즐은 "이것만 알아채면 나머지가 무너지는" 관찰 하나를 가진다.
   `tb-05`의 지렛대는 "7인 판에 외지인은 0 아니면 2"다. 그 관찰이 없으면 경우를 다 세야 한다.
2. **모든 정보가 일한다.** 정보 하나를 빼면 해가 둘로 갈라져야 한다. 안 그러면 그 정보는
   장식이다 — 장식은 풀이자를 헤매게만 한다. 초안에서 정보를 하나씩 빼 보며 확인한다.
3. **붉은 청어가 있다.** 그럴듯하지만 틀린 가설이 하나는 있어야 "아하"가 생긴다. 악역의
   거짓말이 그 역할을 한다 — 진실 주장과 **구별되지 않는 형식**으로 써야 한다.
4. **추론 사슬은 3~7단계.** 해설이 12단계를 넘으면 브루트포스다. 2단계면 퀴즈가 아니다.
5. **대본은 넓게, 답은 좁게.** 풀이자가 세울 수 있는 가설의 수(풀 크기)와 정답에 이르는
   길의 수(1)의 차이가 난이도의 실체다.
6. **한 퍼즐에 한 트릭.** 승계와 이발사와 건달을 한꺼번에 넣으면 유일해도 안 나오고 재미도 없다.

### 9.2 트릭 카탈로그

| 트릭 | 재료 | 예 |
|---|---|---|
| 구성 증명 | 인원별 외지인 수 + 남작/대부/팡 구 | 외지인 주장이 수를 넘친다 → 남작 존재 (`tb-05`) |
| 등록 흔들기 | 은둔자·첩자 + 요리사/초공감자/수사관 | "이웃 악 1"이 은둔자 때문인가 진짜 악인가 |
| 진짜 같은 거짓 | 주정뱅이 + 정보 역할 | 정직한 두 주장이 모순 → 하나는 취했다 |
| 독인가 술인가 | 독살범 + 주정뱅이 | 틀린 정보의 범인 가르기 |
| 죽은 악마 만세 | 탕녀/스타 패스 + 장의사 | 악마 처형 확인 후에도 사람이 죽는다 (`mx-04`) |
| 점프 | 팡 구 + 외지인 | 첫 외지인 킬에 아무도 안 죽었다 |
| 이력의 진위 | 이발사/마귀할멈 + `asRole`/`roleChange` | "원래 X였다"는 주장이 진짜인가 |
| 역전 | 철학자 + 같은 역할 두 주장 | 진짜 쪽이 취해 있고 철학자 정보가 맞다 |
| 조용한 밤 | 군인/수도사/구마사제/**건달** 없음 | 왜 아무도 안 죽었나 → 설명 후보가 하나뿐 |
| 다중 사망 | 암살자/대부/할머니 | 한 밤 2사망 → 암살자 사용 확정 → 하수인 좁히기 |
| 지연 킬 | 푸카 | 죽기 직전 밤의 정보가 중독 정보 |
| 진영 전환 | 건달 + 초공감자/신탁 | 이웃 악 수가 밤마다 바뀐다 |
| 낮 행동 | 처녀/사냥꾼/투표 + 꽃파는 소녀/마을 서기 | 발동·불발이 등록을 못박는다 |
| 거짓의 강제 | 보르톡스 | 모든 주민 정보가 거짓이어야 성립 — 참인 정보가 하나면 보르톡스 탈락 |
| 고백 | 뱀 조련사 | "내가 악마였다"는 주장이 진짜인가 연극인가 |

### 9.3 재미를 죽이는 것

- 대본이 좌석 수와 같다 (정답이 보인다).
- 정보 역할이 밤1에만 있고 밤이 3개다 (뒤의 밤이 놀고 있다).
- 악역의 거짓말이 형식부터 어색하다 (정보 형태가 정직한 주장과 다르다).
- 유일해가 "이 좌석은 악역이 될 수 없다"의 나열로만 나온다 (지렛대가 없다).
- 관대 집합(노 다시·푸카·비고르모르티스)을 정답 세계에 두고 유일해를 기대한다 — 정답 세계의
  정보가 무제약이 되어 오히려 해가 늘어난다.
- 수학자를 넣는다 — 탐색이 무거워지고, 취함 원천마다 값이 흔들려 유일해가 잘 안 나온다.

### 9.4 난이도 기준 (수록 퍼즐 관례)

| 난이도 | 인원 | 밤 | 판본 | 특징 |
|---|---|---|---|---|
| easy | 5~7 | 1~2 | TB 단일 | 트릭 하나, 취함 원천 하나, 승계 없음, 해설 3~5단계 |
| normal | 7 | 2 | TB 단일 | 취함 원천 둘 또는 구성 트릭, 해설 5~7단계 |
| hard | 7~9 | 2~3 | 혼합 또는 승계 | 승계·역할 타임라인·진영 전환 중 하나, 해설 7~10단계 |

## 10. 해설·힌트·질문

### 10.1 해설 (walkthrough) — **솔버가 검증하지 않는 유일한 곳**

솔버는 답이 하나임을 증명할 뿐 해설의 논증이 맞는지는 보지 않는다. 그럴듯하지만 틀린 해설은
그대로 배포된다. 그래서 해설은 **사람(또는 상위 모델)이 반드시 읽는다.**

- 번호를 붙인다: ①, ②, … 각 단계는 "관찰 → 결론" 한 쌍.
- 첫 단계는 전제(구성·대본·시간축)에서 시작한다. 마지막 단계는 사건의 재구성 서사로 닫는다.
- 좌석은 알파벳, 역할은 한국어 표기 (`roleLabel` 규약과 같게).
- 솔버가 열거하는 비결정 변수(붉은 청어·독살 대상·스위트하트 취함 대상)는 해설에서 "∃"로
  얼버무리지 말고 정답 세계의 값을 말한다.
- 해설에서 쓴 논리를 **거꾸로 검산**한다: "④에서 G가 악역이면 세탁부 D의 정보가 성립하지
  않는다" → 실제로 G 악역 세계를 솔버에 넣어 0개인지 본다 (§2.3의 임시 테스트로 `claims`를
  바꿔 돌린다).

### 10.2 힌트

최대 2개. 첫 힌트는 **어디를 볼지**(지렛대의 위치), 둘째는 **핵심 모순**을 말한다. 답을 말하지
않는다. 쉬운 퍼즐은 힌트 없이 두어도 된다.

### 10.3 질문

- 첫 질문은 언제나 `{ id: "demon", text: "…악마는 누구인가?", answerSeats: [악마 좌석] }`.
  정답은 `solution`(또는 `currentDemonSeat`)에서 파생되고 테스트가 교차 검증한다.
- 추가 질문은 `id`에 역할 id를 쓴다 (`"drunk"`, `"baron"`, …). 정답 = `solution`에서 그 역할인
  좌석 전부. 그 역할이 정답에 없으면 `answerSeats: []`이지만, 그런 질문은 넣지 않는다.
- 악마 다음 질문은 "찍어서 맞힌 사람을 거르는 보너스"다. 퍼즐의 핵심 반전(주정뱅이가 누구였나,
  남작이 누구인가)을 묻는다. 5개 이하.

### 10.4 제목 — 트릭을 말하지 않는다

제목은 목록과 풀이 화면에서 **가장 먼저 읽히는 한 줄**이다. 여기서 지렛대를 흘리면 풀이자는
생각을 시작하기 전에 답의 방향을 받아 버린다. 좋은 해설을 써 놓고 제목으로 그것을 무르지 말 것.

**쓰면 안 되는 것**

| 금지 | 나쁜 예 |
|---|---|
| 역할 이름 | "시계는 하나를 가리킨다"(시계공), "능력을 빼앗긴 사람"(철학자) |
| 역할군·구성 | "있어선 안 될 외지인"(외지인 수 증명), "편을 바꾼 이웃"(건달) |
| 관측 지문 그대로 | "처형한 날의 밤은 조용하다"(좀부울), "양옆이 함께 틀렸다"(노 다시), "죽기 전에 이미 취해 있었다"(푸카) |
| 결론·반전 | "옮겨 앉은 악마"(팡 구 점프), "역할이 바뀐 사람"(마귀할멈), "아무도 맞지 않았다"(보르톡스) |

**써도 되는 것**: 이미 헤더에 공개된 사실(인원수·밤 수), 장면과 분위기, 마을의 심경.
"여섯 사람의 첫 아침", "사흘째 종소리", "낯익은 얼굴들"처럼 어느 트릭에도 붙을 수 있는 제목이 좋다.

**판정법**: 제목과 대본만 보여 줬을 때 후보 트릭이 하나로 좁혀지면 실패다. 둘 이상이 남아야 한다.

**오해를 부르는 제목도 피한다.** 없는 단서를 암시하는 제목(조용한 밤이 없는데 "침묵",
승계가 없는데 "이어받은 자")은 힌트는 아니지만 시간을 낭비시킨다. 붉은 청어는 주장 안에서
만들고 제목으로는 만들지 않는다.

**파일 상단 주석은 예외다.** `// 어려움: 노 다시 — 선한 사람 둘이 동시에 틀렸다` 같은 한 줄은
제작자용이고 화면에 나오지 않으므로 트릭을 그대로 적어 두는 편이 낫다. 나중에 목록을 훑을 때
무엇이 이미 쓰인 트릭인지 한눈에 보인다.

## 11. 흔한 실패와 대응

### 11.1 해가 0개

| 원인 | 찾는 법 |
|---|---|
| 정직한 주장이 정답 세계에서 거짓 | 좌석마다 정답 그리모어에서 값을 다시 계산한다. 초공감자는 **킬 이후** 이웃, 요리사는 인접 쌍, 세탁부류는 `targets` 중 하나가 정말 그 역할인가 |
| 깨지 않는 밤의 정보 | §6의 "깨는 밤". 장의사는 전날 처형이 있어야, 저글러는 밤2만, 수도사는 밤2부터 |
| 조용한 밤에 설명이 없다 | §7.1 — 군인·수도사·독살범·건달 중 하나를 넣거나 사망을 넣는다 |
| 죽음에 귀속 수단이 없다 | §7.2 |
| 보호받는 좌석이 죽었는데 독살범이 없다 | §7.3 |
| 외지인 슬롯 계산 | §4 — `슬롯 − 공개 외지인 주장 ∈ {0,1}` |
| 악마가 처형됐는데 승계 수단이 없다 | 탕녀(생존 5인 이상)·마스터마인드(마지막 낮)·좀부울뿐 |
| 첫 밤 사망 | 밤1 사망은 불가 |
| `currentDemonSeat` 누락 | 승계 퍼즐은 필수 |

### 11.2 해가 2개 이상

출력된 세계들을 나란히 놓고 **다른 좌석 하나**를 찾는다. 그 좌석의 역할을 가르는 정보를 추가한다:
세탁부류(둘 중 하나), 장의사(처형자 토큰), 몽상가(둘 중 하나), 초공감자(이웃 수). 정보를 더하기
전에 **대본에서 역할을 빼는 것**도 방법이다 — 하지만 §5.1의 "넉넉한 풀"과 충돌하므로 마지막 수단.

건달 퍼즐에서 그리모어가 같은데 진영만 다른 해 두 개가 나오면, 마지막 밤의 초공감자·신탁·재봉사로
진영을 못박는다.

### 11.3 구조 검사 오류

§5의 표에서 메시지를 찾는다. 대부분 조합 거부(§5.3)·주장 불가 역할(§5.2)·범위(§3.2)다.

### 11.4 탐색이 느리다

10인, 밤 4~5, 수학자, 세레노부스(풀의 모든 선한 역할이 배정 가능), 관대 집합 데몬은 각각
탐색을 크게 늘린다. 두 개 이상 겹치면 테스트가 수십 초를 넘을 수 있다. 하나로 줄인다.

## 12. 체크리스트

퍼즐 하나를 올리기 전에:

- [ ] 정답 그리모어를 먼저 정하고, 선한 좌석의 주장을 그 세계에서 **계산**했다
- [ ] 대본이 §5.1·§5.3·§5.4를 만족한다 (조합 거부표 확인)
- [ ] 판본 태그가 대본과 맞는다 (`mixed` 여부)
- [ ] 외지인 슬롯 계산이 맞는다 (§4)
- [ ] 조용한 밤마다 설명이 있고, 다중 사망마다 귀속 수단이 있다 (§7)
- [ ] 임시 테스트로 돌려 **해 1개**, `solution`·`currentDemonSeat`와 일치
- [ ] 정보를 하나씩 빼 보며 전부 일하는지 확인했다 (§9.1-2)
- [ ] 해설 각 단계를 거꾸로 검산했다 (§10.1)
- [ ] 첫 질문이 `demon`, 추가 질문의 정답이 `solution`에서 나온다
- [ ] 힌트 ≤ 2, 좌석당 정보 ≤ 5, 제목 ≤ 60자
- [ ] **제목이 트릭을 말하지 않는다** (§10.4의 판정법으로 확인)
- [ ] `index.ts`에 등록하고 `npm test` 전체 통과
- [ ] 임시 테스트 파일을 지웠다

## 13. 모델에게 시킬 때

이 문서를 통째로 주고 §1의 흐름을 따르게 한다. 다음을 명시한다:

- **정답 그리모어를 먼저 쓰고 주장을 계산하라.** 주장을 먼저 지어내면 거의 항상 0개가 나온다.
- **한 퍼즐에 트릭 하나.** §9.2에서 고르게 하고 이름을 말하게 한다.
- **§2.3의 임시 테스트로 매번 돌려라.** 해 개수와 세계 목록을 보고 판단하게 한다.
- **해설은 제출물이지 검증물이 아니다.** 해설의 논증은 사람이 본다고 알려 준다.
- **조합 거부표와 역할별 대본 조건(§5.3·§5.4)을 먼저 확인하라.** 특히 마귀할멈·건달·이발사.
- 유일해가 안 나오면 대본을 줄이지 말고 **구별 정보를 더하라** (§11.2).
- 완성되면 §12 체크리스트를 채워 보고하게 한다.

배포 게이트가 틀린 퍼즐을 막으므로 초안 생성에는 상위 모델이 필요 없다. 상위 모델(또는 사람)은
**해설의 논증**과 **재미**(§9)를 본다.
