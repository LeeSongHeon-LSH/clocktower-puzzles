# 요구사항 — 시계탑 퍼즐 (clocktower-puzzles)

> 2026-08-27 설계 인터뷰(그릴링 세션)에서 합의된 내용. 변경 시 이 문서를 갱신한다.

## 1. 프로젝트 목적

- 보드게임 **Blood on the Clocktower**(시계탑에 흐른 피)의 **상황 추리 퍼즐**을 웹에서 풀 수 있는 공개 사이트.
- 1차 대상: 심심풀이로 퍼즐을 풀고 싶은 사람. 계정 없이 URL만으로 접속.
- 장기 방향: 텔러(스토리텔러) 보조 웹앱으로 발전 가능성. 이번에 만드는 **솔버(룰 엔진)** 는 그때의 핵심 자산이 된다.
- 비공식 팬 프로젝트임을 명시한다 (The Pandemonium Institute 공식 아트/아이콘 사용 금지, 소개 페이지에 고지문).

## 2. 퍼즐 콘텐츠

### 2.1 형식: 공개 주장 기반 상황 추리
- 모든 플레이어(생존자)가 자신의 역할과 밤 정보를 **공개 주장**한 상황을 제시한다.
- 악역·술꾼 등은 거짓 주장이 가능하다. 풀이자는 "어떤 배정(그리모어)이어야 전체 주장이 정합적인가"를 추리한다.
- **다일차 타임라인** 지원: 처형·사망 이벤트, "N일차 밤에 본 정보" 표현 가능.
- 좌석명은 현실 이름 대신 **알파벳(A, B, C, …)**. 좌석 순서 = 배열 순서(원형 인접 판정에 사용).

### 2.2 풀이 상호작용
- 문제마다 **단계형 서브 질문** 배열 (예: "데몬은 누구인가?" → "술꾼은 누구인가?").
- **무제한 재시도**, "포기" 버튼 제공. 정답 또는 포기 전까지 해설 잠금.
- **힌트 최대 2개** (클릭해서 열람, 안 쓴 문제는 비워둠).
- 해설은 **단계별 추론 워크스루** (①, ②, … 논리 사슬).

### 2.3 초기 볼륨과 분류
- 출시 시 **10문제**: 쉬움 3(TB) + 보통 3(TB) + 어려움 4(SV/BMR 역할 혼합).
- 태그: 난이도(easy/normal/hard), 에디션(tb/bmr/sv/mixed), 인원수.
- 에디션 범위: 공식 3에디션 (Trouble Brewing, Bad Moon Rising, Sects & Violets). 실험 캐릭터는 추후.

### 2.4 지원 역할 (솔버가 모델링하는 역할만 퍼즐에 등장 가능)
- TB 정보 역할: Washerwoman, Librarian, Investigator, Chef, Empath, Fortune Teller, Undertaker, Ravenkeeper
- TB 교란원·악역: Drunk, Recluse, Poisoner, Spy, Baron, Scarlet Woman, Imp
- 어려움 문제용 SV/BMR: Clockmaker, Seamstress, Juggler, Mathematician, Chambermaid

### 2.5 정합성 검증 (핵심 요구사항)
- 모든 퍼즐은 **솔버가 전수 탐색으로 유일해임을 기계 증명**해야 한다.
- 퍼즐별 검증이 테스트 스위트로 돌며, 실패하면 배포 불가.
- 솔버는 개발용 도구로만 사용 (앱 UI에 노출하지 않음 — 스포일러 방지).
- 제작 흐름: Claude가 초안 생성 → 솔버 검증 통과 → 사용자 최종 검수.

## 3. 언어·표기

- UI 언어: 한국어.
- 역할명: **한국어(영어 병기)** — 예: "임프(Imp)", "부정한 여인(Scarlet Woman)".
- 번역 초안은 Claude가 작성하되 한국 커뮤니티/위키 통용 표기와 대조해 교정한다.
- 확정 표기: Scarlet Woman = **부정한 여인**.
- 진영 용어: Townsfolk=마을 사람, Outsider=외부인, Minion=하수인, Demon=데몬.
- **역할명은 앱 내 관리자 페이지에서 수정 가능해야 한다** (피드백 즉시 반영 목적, §5.4).

## 4. 화면

| 페이지 | 내용 |
|---|---|
| 홈(목록) | 퍼즐 카드 목록, 난이도·에디션 필터, 풀이 완료·첫 시도 성공 ⭐ 배지 |
| 퍼즐 | 타운스퀘어 SVG 원형 배치도 + 밤 정보 로그(상시 표시) + 서브 질문 답 제출 + 힌트 + 해설 |
| 소개 | 앱 설명, 팬 콘텐츠 고지문 |
| 관리자 | 역할명 한국어 표기 편집 (비밀번호 잠금) |

- 타운스퀘어: 좌석 탭 → 해당 플레이어의 주장·정보 표시. 답 제출 모드에서는 좌석 탭 = 지목.
- **모바일 우선** 설계.
- 비주얼 톤: 모던한 레이아웃 + BotC 색감·서체 포인트(고딕/다크 무드 절충). 공식 아트 미사용.

## 5. 데이터·저장

### 5.1 퍼즐 데이터
- 문제 1개 = 리포지토리 내 TS 파일 1개 (`src/data/puzzles/`). 타입 스키마로 검증.
- 사람용 서술(`text`)과 솔버용 구조화 데이터를 병기.

### 5.2 풀이 기록
- **localStorage**만 사용 (계정·DB 없음): 푼 문제, 첫 시도 성공 여부.

### 5.3 정답 데이터
- 각 퍼즐 파일에 정답 그리모어(`solution`)와 서브 질문 정답 포함. 솔버 테스트가 유일해와 일치 여부를 검증.

### 5.4 역할명 편집 (관리자)
- 관리자 페이지에서 수정 → 서버 API가 **GitHub API로 역할 사전 파일을 커밋** → Vercel 자동 재배포(~1분 내 전체 반영).
- 리포지토리가 유일한 진실 원본. 수정 이력은 git에 남는다.
- 인증: 환경변수 비밀번호 1개 (`ADMIN_PASSWORD`). GitHub 토큰은 Vercel 환경변수(`GITHUB_TOKEN`).

## 6. 배포

- 호스팅: **Vercel** (외부 접속 가능해야 함 — 사이트는 URL을 아는 누구나 접속).
- 리포: GitHub private `LeeSongHeon-LSH/clocktower-puzzles`. push → 자동 배포.
- Vercel 프로젝트 연결은 사용자가 웹에서 1회 수행.
